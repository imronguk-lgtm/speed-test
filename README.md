# speed-test

Консольный скрипт на Node.js, который замеряет скорость скачивания. Он делает 10 последовательных запросов к одному адресу и дожидается полного ответа на каждый. По итогам выводит среднее время запроса, общий объём скачанного и скорость.

## Требования

Node.js 18 или новее: нужен встроенный `fetch`. Сторонних зависимостей нет, `npm install` не нужен.

## Запуск

```bash
git clone https://github.com/imronguk-lgtm/speed-test.git
cd speed-test
node speedtest.js https://example.com/big-image.jpg
```

Аргументы:

| Аргумент | Обязательный | По умолчанию |
|---|---|---|
| адрес (http/https) | нет | `https://speed.cloudflare.com/__down?bytes=10000000` (файл 10 МБ) |
| количество запросов | нет | `10` |

Примеры:

```bash
node speedtest.js
node speedtest.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
node speedtest.js https://speed.cloudflare.com/__down?bytes=25000000 5
```

Также можно запустить через `npm start -- <адрес>`.

## Единицы измерения

- **Время запроса** — в миллисекундах (мс). Отсчёт идёт от отправки запроса до получения последнего байта тела ответа, так что сюда входят DNS, соединение, TLS и ожидание сервера.
- **Объём** — в мегабайтах, 1 МБ = 1 000 000 байт.
- **Скорость** — основная единица мегабиты в секунду, 1 Мбит/с = 1 000 000 бит/с. Это та же единица, в которой провайдеры указывают тарифы. В скобках выводится то же значение в МБ/с.

Скорость считается так: все скачанные байты × 8 / суммарное время всех успешных запросов. Скорость каждого запроса тоже выводится, отдельной строкой.

## Как это работает

- Запросы идут строго по очереди: каждый следующий ждёт, пока предыдущий скачается целиком (`await` внутри цикла `for`).
- Тело ответа читается потоком (`for await` по `response.body`), байты считаются по факту получения. На заголовок `Content-Length` скрипт не опирается: его может не быть, а при сжатии он не равен реальному объёму.
- Чтобы повторные запросы не отдавались из кэша, к адресу добавляется случайный параметр `_nocache`, а у запроса стоит `cache: 'no-store'`.
- На один запрос даётся 60 секунд. Если запрос упал (ошибка сети, ответ не 2xx, таймаут), он выводится как ошибка и не учитывается в итогах.
